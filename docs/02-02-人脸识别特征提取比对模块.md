## 一、功能背景

检测模块只能回答「人脸在哪」，要回答「这是谁」，必须把一张人脸压缩成一个**可比较的定长向量**，并在向量空间中用距离度量身份。

FaceNet 的核心思想（Schroff et al., 2015）：用三元组损失（Triplet Loss）直接学习一个**欧氏空间嵌入**，使「同一人的不同照片」距离近、「不同人」距离远。其产物是一个 **512 维**特征向量，具有两条关键性质：

1. **同一人不同角度/光照/表情下，向量变化小**（类内紧凑）；
2. **不同人之间向量差异大**（类间可分）。

工程上再叠加 **L2 归一化**后，欧氏距离与余弦相似度满足单调关系：

```text
||a - b||² = ||a||² + ||b||² - 2·(a·b) = 2 - 2·cos(a,b)     (当 ||a|| = ||b|| = 1)
```

即**向量的点积就等于余弦相似度**，比对退化为一次矩阵乘法，这是本模块性能的关键设计。

## 二、开发目标

| 目标 | 说明 |
|------|------|
| FaceNet 加载 | 加载 InceptionResnetV1（`casia-webface` 预训练权重），输出 512 维嵌入 |
| 特征提取 | 输入人脸 ROI（BGR）→ 输出 `(1, 512)` 的 `float32` 特征向量 |
| L2 归一化 | 输出向量模长恒为 1，使点积 = 余弦相似度 |
| 余弦比对 | 提供「一查全库」比对：查询特征与 SQLite 中全部特征计算余弦相似度并取最高分 |
| CPU/GPU 自适应 | 自动探测 `torch.cuda.is_available()`，有 GPU 用 GPU，无 GPU 降级 CPU |
| 推理安全 | 全程 `torch.no_grad()`，避免显存/内存泄漏 |

## 三、功能职责

`backend/face_recognition.py` 对外暴露一个类 `FaceRecognition`，承担三件事：

1. **模型托管**：加载/持有 FaceNet 模型，管理层设备（CPU/CUDA）与 `eval` 模式；
2. **特征提取**：人脸 ROI → 前处理 → 推理 → L2 归一化 → 特征向量；
3. **特征比对**：从 `face_db` 读取全部特征，计算查询特征与库内每条特征的余弦相似度，按阈值判定身份。

**不做的事**（职责边界）：

- 不做人脸定位（→ `face_detection.py`）；
- 不做特征的持久化（→ `db_utils.py`）；
- 不做绘制与交互（→ `main.py` / `api_server.py`）。

## 四、功能逻辑

### 4.1 类结构（实际实现）

```python
class FaceRecognition:
    _model = None                     # 类变量：模型全局复用
    _device = None                    # 'cuda' / 'cpu'

    @classmethod
    def _get_model(cls)               # 懒加载 InceptionResnetV1('casia-webface').eval()
    @classmethod
    def extract_feature(cls, face_img)
        # 入参可为图片路径(str)或 BGR ROI(ndarray) → (1, 512) float32，失败返回 None
    @classmethod
    def recognize_face(cls, face_image, threshold=0.6)
        # 提特征 → 读取全库 → sklearn 余弦相似度 → 取最高分 → {'name', 'similarity'} / None
```

> 该类**不提供自定义构造器**、`extract_features()`、`compare()` 或 `match_against_db()`；模型、设备与阈值均由类方法/参数管理。接口层为支持 N 张脸批量比对，直接复用 `extract_feature()`，自行完成一次取库与矩阵运算（见 `docs/03-03`）。

### 4.2 特征提取流程

```text
人脸 ROI (BGR, 任意尺寸) 或 图片路径(str)
   │
   ├─ 路径入参: os.path.exists → np.fromfile + cv2.imdecode
   │      └─ 文件不存在 / 解码失败 → 打印 Error! 并返回 None
   ├─ cvtColor(BGR2RGB)                      FaceNet 权重基于 RGB 训练
   ├─ resize(160, 160)                       与 InceptionResnetV1 输入尺寸一致
   ├─ torch.tensor(...).permute(2,0,1)       HWC uint8 → CHW
   ├─ .float() / 255.0                       → [0, 1]（当前未做 mean/std 标准化）
   ├─ unsqueeze(0).to(device)                → NCHW (1,3,160,160)
   │
   ▼
with torch.no_grad():
    model(face_tensor)                        → (1, 512) 未归一化嵌入
   │
   ├─ torch.norm(p=2, dim=1, keepdim=True)   → L2 范数
   ├─ embedding / l2_norm                    → 模长 = 1
   └─ .cpu().numpy()                         → (1, 512) float32
   │
   ▼
(1, 512) float32 特征向量；任一步异常 → 打印 Error! 并返回 None
```

### 4.3 比对流程（`recognize_face`）

```text
查询人脸 ROI
   │
   ├─ extract_feature(q)                     → (1, 512)；None → return None
   ├─ face_db.get_all_features()             → D (N, 512) + info_list
   │      └─ 空库 → 打印 Warning!, return None
   ├─ cosine_similarity(q, D)[0]             → (N,) 每项为余弦相似度
   ├─ idx = argmax(sims); score = sims[idx]
   │
   └─ score >= threshold ?
        ├─ 是 → {'name': info_list[idx]['name'], 'similarity': score}
        └─ 否 → 打印最高分与阈值, return None
```

> `recognize_face()` 面向 CLI 单脸调用：**每次调用取一次全库**。API 层为避免多脸请求重复取库，改为「每请求一次取库 + 逐脸 `matrix @ feature`」，算法口径同为余弦相似度、默认阈值 0.6。

### 4.4 CPU / GPU 自动切换逻辑

| 判定 | 行为 |
|------|------|
| `torch.cuda.is_available() == True` | `device = 'cuda'`；模型与输入张量均 `.to('cuda')`；打印 `FaceNet 模型加载完成(设备：cuda)` |
| `torch.cuda.is_available() == False` | `device = 'cpu'`；同一套代码自动降级，功能等价，仅推理速度较慢 |

> 自动切换保证同一份代码在「开发机（无 GPU）」与「部署机（有 GPU）」上均可运行，无需改配置。

### 4.5 输入与输出

| 方法 | 输入 | 输出 | 异常 / 失败行为 |
|------|------|------|----------------|
| `_get_model()` | — | `InceptionResnetV1` 实例 | `ImportError`：未安装 `torch` / `facenet-pytorch`；权重下载失败时由 torch/facenet 抛异常（未包装） |
| `extract_feature(face_img)` | 图片路径 `str` 或 BGR `np.ndarray` | `(1, 512)` `np.float32`，L2 模长 ≈ 1 | 路径不存在 / 解码失败 / 通道或推理异常时打印 `Error!` 并返回 `None`；模型加载失败发生在 `try` 之前，会向上抛异常 |
| `recognize_face(face_image, threshold=0.6)` | 人脸 ROI（或路径）+ 阈值 | `{'name': str, 'similarity': float}`，未达阈值或空库返回 `None` | 相似度取未取整 float；空库打印 `Warning!` |

### 4.6 关键参数

| 参数 | 取值 | 说明 |
|------|------|------|
| 特征维度 | **512** | InceptionResnetV1 最后全连接层之前输出的嵌入维度 |
| 输入尺寸 | **160 × 160** | FaceNet 系列标准输入，尺寸不符会显著掉精度 |
| 像素归一化 | `float() / 255.0` | 当前实现将像素映射到 `[0,1]`；未使用官方示例的 `(x-0.5)/0.5` |
| L2 归一化 | 开 | 使用 `torch.norm`，使点积 = 余弦相似度，可与阈值直接比较 |
| 识别阈值 | **0.6** | `recognize_face()` 默认参数；建议 0.5~0.7 区间标定 |
| 推理模式 | `no_grad` + `eval` | 关闭梯度与 Dropout/BatchNorm 训练行为 |
| 模型复用 | 类变量 `_model` | 全进程只加载一次，避免重复占用显存 |

## 七、异常点与坑点

| # | 问题 | 现象 | 处置 |
|---|------|------|------|
| 1 | **输入尺寸必须 160×160** | 传入任意尺寸 ROI 直接喂模型 → 维度报错或精度骤降 | 前处理强制 `resize((160,160))`，与权重训练尺寸严格对齐 |
| 2 | **BGR / RGB 通道顺序** | OpenCV 读图是 BGR，而 FaceNet 权重按 RGB 训练；不转换会使相似度整体下移、同人不同图差异放大 | 提取前统一 `cvtColor(BGR2RGB)` |
| 3 | **忘记 `eval()` / `no_grad()`** | 训练态 BatchNorm/Dropout 生效导致结果不稳定；无 `no_grad` 会持续累积计算图 | 载入即 `net.eval()`，推理全程 `with torch.no_grad()` |
| 4 | **权重首次运行需联网下载** | 国内网络访问 GitHub Release 常超时，表现为卡住或 `URLError` | 见 `temp/TORCH_INSTALL_GUIDE.md` 的手动下载 + 离线放置方案 |
| 5 | **未做 L2 归一化直接用欧氏距离** | 相似度阈值失去物理意义，阈值需重新标定 | 统一 L2 归一化后使用点积（= 余弦相似度）与固定阈值 0.6 |
| 6 | **特征以 `float64` 存储或比对** | 与 `db_utils` 的 `float32` BLOB 不一致，`frombuffer` 还原后数值错乱 | 端到端统一 `np.float32`：提取即 `.astype(np.float32)`，存储按 `float32` 序列化 |
| 7 | **CUDA 显存不足** | 批量提取大量人脸时 `CUDA out of memory`（本机 RTX 4060 Laptop 仅 8 GB） | 逐个 ROI 推理或小 batch（≤16），必要时 `torch.cuda.empty_cache()` |
| 8 | **`torch` 与 `numpy 2.x` / Python 版本不匹配** | 导入即报 `DLL load failed` 或 `undefined symbol` | 安装与 Python 3.11 匹配的 torch wheel；见安装指导文档 |
| 9 | **`facenet-pytorch` 会连带重装 torch** | 若先装 facenet-pytorch，pip 可能拉入不匹配的 torch 构建 | 安装顺序：**先 torch（选定 CPU/CUDA 源），后 facenet-pytorch（必要时 `--no-deps`）** |
| 10 | 阈值是经验值而非绝对判据 | 不同数据域（亚洲人脸、监控画质）最佳阈值不同 | 建议用本项目样本集在 0.5~0.7 区间做标定后再固化 |
| 11 | `casia-webface` 与 `vggface2` 权重不可混用 | 两个权重的特征空间不同，混用会导致同人相似度骤降 | 全项目统一使用 `casia-webface`；如更换权重，**必须清空特征库重新录入** |
| 12 | **输入标准化与官方示例不一致** | 当前仅 `float()/255` 到 `[0,1]`，未按 facenet-pytorch 常见示例做 `(x-0.5)/0.5` | 现有同人样例仍可 ≥0.6，暂不改动；若后续识别精度不足，应统一改为 mean=0.5 / std=0.5 并**清空旧库重录**（特征空间会变化） |
