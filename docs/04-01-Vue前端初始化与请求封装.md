## 一、功能背景

阶段 3 交付了 7 个 HTTP 接口，业务能力已经完整，但全部调用入口仍停留在 `curl` 与 Swagger UI：

| 现状 | 使用门槛 | 业务缺口 |
|------|----------|----------|
| `/docs` 点测 | 需要理解 multipart / JSON / base64 三种入参形态 | 无法连续操作，刷新即丢状态 |
| `curl` 脚本 | 需要手工构造 `FormData`、URL 编码中文姓名 | 无法预览图片与人脸框 |
| `frontend/` 目录 | 仅有 `.gitkeep` 占位 | 浏览器侧零代码 |

阶段 4 的目标是「浏览器完成全部业务」。**第一件事不是写页面，而是把工程与请求层立起来**，原因有三：

1. 4 个业务页面共用到全部 7 个接口，请求地址、超时、错误码处理若各写一遍，必然漂移；
2. 后端返回的是 `{code, message, data}` 信封，且 `422 / 429 / 500` 由全局处理器统一包装——如果每个页面各自判断 `response.data.code`，会出现「有的页面弹错、有的页面白屏」；
3. 实时识别页对超时与丢帧的要求（5 s、静默丢弃 `1008`）与图片识别（60 s、必须提示 `1008`）完全不同，必须由封装层按接口区分策略。

技术选型对比：

| 方案 | 优点 | 缺点 | 结论 |
|------|------|------|------|
| **Vite + Vue3** | 冷启动毫秒级、原生 ESM、`vite.config.js` 即可配端口/代理；与总纲技术栈一致 | 生产部署需 `npm run build` 静态托管 | ✅ 选用 |
| Vue CLI（webpack） | 生态旧资料多 | 启动慢、依赖树重、Vue3 支持属维护模式 | ✗ |
| Nuxt3 | SSR/文件路由开箱即用 | 本项目为单机内网工具，SSR 无收益，反而增加 node 服务端 | ✗ |
| 原生 HTML + fetch | 零构建 | 5 个页面 + 复用摄像头逻辑需手写路由/组件，维护成本高 | ✗ |

UI 与 HTTP 库对比：

| 维度 | 选项 A：无 UI 库 + 手写 CSS | 选项 B：Element Plus | 结论 |
|------|---------------------------|----------------------|------|
| 体积 | 无额外依赖 | 约 1 MB（含样式） | A |
| 页面数量 | 5 个页面、控件仅按钮/输入/表格/滑块 | 组件齐全但大部分用不上 | A |
| 教学透明度 | 布局与交互全部可见 | 组件黑盒，问题定位需读库源码 | A |
| 开发效率 | 需手写基础样式（一次性） | 表格/弹窗可直接用 | B |

> **结论**：选择 **A（无 UI 库）**，用一套 CSS 变量 + `scoped` 样式统一观感；请求库按总纲要求使用 **axios**（拦截器、超时、`AbortController`、`onUploadProgress` 均为本项目刚需，`fetch` 需自行封装同等能力）。

**不做的事**（职责边界）：

- 不实现采集 / 识别 / 特征库业务逻辑（→ `docs/04-02` ~ `docs/04-05`）；
- 不做登录、鉴权、多用户（后端无用户体系，单机部署）；

- 不做 SSR、不做 i18n（界面固定中文，与后端 `message` 一致）；
- 不修改后端任何接口与 `CORS` 配置（阶段 3 已放行 5173 / 4173 的 `localhost` 与 `127.0.0.1`）。

### 4.4 axios 实例封装

```js
// frontend/src/api/http.js
import axios from 'axios'

const rawBaseUrl = import.meta.env.VITE_API_BASE_URL || 'http://127.0.0.1:8000/api'

export const API_BASE_URL = rawBaseUrl.replace(/\/+$/, '')                       // 去掉尾部斜杠
export const STATIC_ORIGIN = (
  import.meta.env.VITE_STATIC_ORIGIN || API_BASE_URL.replace(/\/api$/, '')
).replace(/\/+$/, '')

export class ApiError extends Error {
  constructor(code, message, status = 0) {
    super(message)
    this.name = 'ApiError'
    this.code = code        // 0 成功；>0 业务错误；<0 前端网络/超时/取消
    this.status = status    // HTTP 状态码，网络错误为 0
  }

  get isBusy() { return this.code === 1008 }        // 推理繁忙：实时页静默丢帧
  get isCanceled() { return this.code === -3 }      // 主动取消：不提示
  get isNetwork() { return this.code === -1 || this.code === -2 }
}

const http = axios.create({
  baseURL: API_BASE_URL,
  timeout: 30000,
  headers: { Accept: 'application/json' },
})

function unwrap(response) {
  const body = response.data
  if (!body || typeof body.code !== 'number') {
    throw new ApiError(-1, '响应格式异常：缺少 code 字段', response.status)
  }
  if (body.code !== 0) {
    throw new ApiError(body.code, body.message || '请求失败', response.status)
  }
  return body                                  // { code: 0, message, data }
}

http.interceptors.response.use(
  unwrap,
  (error) => {
    const body = error.response && error.response.data
    if (body && typeof body.code === 'number') {          // 422 / 429 / 500 也是信封
      return Promise.reject(new ApiError(body.code, body.message || '请求失败', error.response.status))
    }
    if (error.code === 'ERR_CANCELED') {
      return Promise.reject(new ApiError(-3, '请求已取消', 0))
    }
    if (error.code === 'ECONNABORTED') {
      return Promise.reject(new ApiError(-2, '请求超时：后端推理耗时较长或服务未响应', 0))
    }
    return Promise.reject(new ApiError(-1, '无法连接后端服务，请确认 uvicorn 已在 8000 端口启动', 0))
  },
)

export default http

/** `/static/xxx.jpg` → 完整可访问 URL；已是绝对地址则原样返回 */
export function resolveStaticUrl(path) {
  if (!path) return ''
  if (/^https?:\/\//i.test(path)) return path
  return `${STATIC_ORIGIN}${path.startsWith('/') ? '' : '/'}${path}`
}
```

**封装约定（页面必须遵守）**：

| 约定 | 说明 |
|------|------|
| 返回值已解包 | `await getLibrary()` 得到 `{code, message, data}`，**不是** `AxiosResponse`；取数据用 `res.data` |
| 失败一律 reject | `code !== 0` 不 resolve；页面必须 `try/catch`，否则控制台 `Unhandled rejection` 且无 UI 反馈 |
| `message` 直接用 | 后端提示为中文且已细化到场景（如「姓名[丁真]已存在…」），页面不再拼接 |
| 取消不算错误 | `error.isCanceled` 为 `true` 时直接 `return`，不写提示 |
| 静态资源单独拼 | `/static` 不在 `/api` 下，必须用 `resolveStaticUrl()`，不能拼 `API_BASE_URL` |

### 4.5 接口封装清单

```js
// frontend/src/api/face.js
import http from './http'

export const DEFAULT_THRESHOLD = 0.6
export const THRESHOLD_MIN = 0.3
export const THRESHOLD_MAX = 0.95
export const MAX_UPLOAD_BYTES = 5 * 1024 * 1024
export const MAX_NAME_LEN = 32

export function getHealth({ signal } = {}) {
  return http.get('/health', { timeout: 5000, signal })
}

export function registerByImage(file, name, { onUploadProgress, signal } = {}) {
  const form = new FormData()
  form.append('file', file, file.name || 'upload.jpg')
  form.append('name', name.trim())
  return http.post('/face/register/image', form, { timeout: 30000, onUploadProgress, signal })
}

export function registerByFrame(name, imageBase64, { signal } = {}) {
  return http.post(
    '/face/register/camera-frame',
    { name: name.trim(), image_base64: imageBase64 },
    { timeout: 30000, signal },
  )
}

export function recognizeByImage(file, { threshold = DEFAULT_THRESHOLD, saveResult = false, signal } = {}) {
  const form = new FormData()
  form.append('file', file, file.name || 'upload.jpg')
  form.append('threshold', String(threshold))
  form.append('save_result', saveResult ? 'true' : 'false')
  return http.post('/recognize/image', form, { timeout: 60000, signal })
}

export function recognizeByFrame(imageBase64, { threshold = DEFAULT_THRESHOLD, signal } = {}) {
  return http.post(
    '/recognize/frame',
    { image_base64: imageBase64, threshold },
    { timeout: 5000, signal },          // 实时链路：超时即丢帧，不排队
  )
}

export function getLibrary({ signal } = {}) {
  return http.get('/face/library', { timeout: 10000, signal })
}

export function deleteLibraryItem(name, { signal } = {}) {
  return http.delete('/face/library', { params: { name }, timeout: 10000, signal })
}
```

| # | 函数 | 方法 / 路径 | 入参要点 | 返回 `data` |
|---|------|-------------|----------|-------------|
| 1 | `getHealth()` | `GET /health` | — | `{status, version, device, detector, feature_dim, library_size}` |
| 2 | `registerByImage(file, name)` | `POST /face/register/image` | `FormData`：`file`、`name` | `{record_id, name, face_count, selected, feature_dim}` |
| 3 | `registerByFrame(name, dataUrl)` | `POST /face/register/camera-frame` | JSON：`name`、`image_base64` | 同上 |
| 4 | `recognizeByImage(file, opts)` | `POST /recognize/image` | `file`、`threshold`、`save_result`（字符串） | `{total_faces, matched_count, elapsed_ms, library_empty, faces[], result_image_url}` |
| 5 | `recognizeByFrame(dataUrl, opts)` | `POST /recognize/frame` | `image_base64`、`threshold` | 同上（`result_image_url` 恒为 `null`） |
| 6 | `getLibrary()` | `GET /face/library` | — | `{total, items:[{id,name,timestamp,feature_dim}]}` |
| 7 | `deleteLibraryItem(name)` | `DELETE /face/library?name=` | query `name`（axios 自动 URL 编码） | `{name, deleted}` |

> 字段名严格对齐 `docs/03-02` ~ `docs/03-04`：multipart 用 `file` / `name`，JSON 用 `image_base64`，query 用 `name`。任何一处拼写差异都会得到 `422`，且提示只写 `Field required`。

```js
import { createRouter, createWebHistory } from 'vue-router'

const routes = [
  { path: '/', name: 'home', component: () => import('../views/HomeView.vue'), meta: { title: '首页' } },
  { path: '/collect', name: 'collect', component: () => import('../views/FaceCollect.vue'), meta: { title: '人脸采集' } },
  { path: '/recognize/image', name: 'recognize-image', component: () => import('../views/ImageRecognize.vue'), meta: { title: '图片识别' } },
  { path: '/recognize/camera', name: 'recognize-camera', component: () => import('../views/CameraRealTime.vue'), meta: { title: '实时识别' } },
  { path: '/library', name: 'library', component: () => import('../views/FaceLibrary.vue'), meta: { title: '特征库管理' } },
  { path: '/:pathMatch(.*)*', redirect: '/' },
]

const router = createRouter({
  history: createWebHistory(import.meta.env.BASE_URL),
  routes,
  scrollBehavior: () => ({ top: 0 }),
})

router.afterEach((to) => {
  document.title = to.meta.title ? `${to.meta.title} · 人脸检测识别系统` : '人脸检测识别系统'
})

export default router
```

### 4.10 通用图片工具（4-2 / 4-3 复用）

```js
// frontend/src/utils/image.js
export const ALLOWED_TYPES = ['image/jpeg', 'image/png', 'image/webp', 'image/bmp']

/** 返回错误文案；合法返回 null。以后端 5 MB 上限为唯一口径 */
export function validateImageFile(file, maxBytes = 5 * 1024 * 1024) {
  if (!file) return '请选择图片文件'
  if (!ALLOWED_TYPES.includes(file.type)) return '仅支持 JPG / PNG / WEBP / BMP 图片'
  if (file.size === 0) return '图片为空，请重新选择'
  if (file.size > maxBytes) return `图片 ${(file.size / 1024 / 1024).toFixed(1)} MB，超过 5 MB 上限`
  return null
}

/** 等比缩放到长边 maxSide，返回 { width, height, scale }；不放大 */
export function scaleSize(width, height, maxSide) {
  const longSide = Math.max(width, height)
  if (longSide <= maxSide) return { width, height, scale: 1 }
  const scale = maxSide / longSide
  return { width: Math.round(width * scale), height: Math.round(height * scale), scale }
}

/** canvas → JPEG dataURL，质量 0~1 */
export function canvasToJpeg(canvas, quality = 0.8) {
  return canvas.toDataURL('image/jpeg', quality)
}

/** 长边 > maxSide 时压缩为 JPEG；≤ threshold 的文件原样返回，避免无谓重编码 */
export async function compressImage(
  file,
  { maxSide = 1600, quality = 0.85, threshold = 800 * 1024, maxBytes = 5 * 1024 * 1024 } = {},
) {
  if (file.size <= threshold) return file
  let source
  let width
  let height
  if (window.createImageBitmap) {
    source = await createImageBitmap(file)          // 默认按 EXIF 方向解码
    width = source.width
    height = source.height
  } else {
    source = await new Promise((resolve, reject) => {
      const img = new Image()
      img.onload = () => resolve(img)
      img.onerror = () => reject(new Error('图片解码失败'))
      img.src = URL.createObjectURL(file)
    })
    width = source.naturalWidth
    height = source.naturalHeight
  }
  const size = scaleSize(width, height, maxSide)
  const canvas = document.createElement('canvas')
  canvas.width = size.width
  canvas.height = size.height
  canvas.getContext('2d').drawImage(source, 0, 0, size.width, size.height)
  source.close?.()
  if (!window.createImageBitmap && source.src) URL.revokeObjectURL(source.src)
  const blob = await new Promise((resolve) => canvas.toBlob(resolve, 'image/jpeg', quality))
  if (!blob || blob.size > maxBytes) throw new Error('图片压缩失败或仍超过 5 MB')
  return new File([blob], `upload_${Date.now()}.jpg`, { type: 'image/jpeg' })
}
```

> `scaleSize` 同时用于 4-2 的拍照帧（长边 640）与 4-3 的预览压缩；**只缩不放**，避免小图被插值放大后反而模糊。

## 七、异常点与坑点

| # | 问题 | 现象 | 定位与处置 |
|---|------|------|------------|
| 1 | **Node 版本过低** | `npm run dev` 报 `crypto.hash is not a function` 或语法错误 | Vite 5 要求 Node ≥ 18.18；`node -v` 确认，必要时用 nvm 切 20 LTS |
| 2 | **在非空目录初始化** | `npm create vite@latest .` 提示 `Current directory is not empty`，选择删除会把 `.gitkeep` 一起清掉或直接中断 | 先把 `frontend/.gitkeep` 移出目录，初始化完成并确认文件齐全后删除该占位文件 |
| 3 | **baseURL 尾部斜杠** | `http://127.0.0.1:8000/api/` + `/health` → `//health`，部分代理返回 404 | 统一 `replace(/\/+$/, '')`，接口路径一律以 `/` 开头 |
| 4 | **按 `AxiosResponse` 习惯取数** | 写 `res.data.data.total` 得到 `undefined`（拦截器已解包，`res` 就是信封） | 约定：`res` = `{code, message, data}`，取业务字段直接用 `res.data`；`res.data.data` 只出现在未解包的原始 axios 调用中 |
| 5 | **422 / 429 / 500 进入 reject** | 只写 `then` 不写 `catch` → 控制台报错但界面无提示 | 响应拦截器两个分支都归一为 `ApiError`；页面必须 `try/catch` |
| 6 | **`save_result` 传布尔** | 某些环境 `FormData.append('save_result', false)` 发送字符串 `"false"`，FastAPI 可解析；但传空值会 422 | 显式 `saveResult ? 'true' : 'false'`，与 `docs/03-03` 坑点 7 一致 |
| 7 | **multipart 字段拼错** | 写成 `image` / `username` → `422`，提示只有 `Field required` | 字段名固化在 `face.js`，页面不再直接构造 `FormData` |
| 8 | **超时设置过短** | CPU 环境识别大图可能 10 s 以上，30 s 仍偏紧；实时帧若沿用 30 s 会堆积 | 图片识别 60 s、采集 30 s、帧 5 s、列表 10 s，按接口分档（见 4.5） |
| 9 | **帧接口 1008 弹窗** | 实时页每 400 ms 请求一次，若把 `1008` 当普通错误弹 toast，会疯狂刷屏 | `error.isBusy` 分支静默返回，保留上一帧结果（`docs/04-04` 4.5） |
| 10 | **CORS origin 不匹配** | 用 `http://localhost:5173` 打开但后端只放行 `127.0.0.1`（或反之）→ 预检失败 | 后端默认两者都放行；自定义端口/IP 时用 `CORS_ORIGINS` 环境变量追加，不要改 `allow_origins=['*']` 掩盖问题 |
| 11 | **`/static` 拼错到 `/api` 下** | `API_BASE_URL + result_image_url` → `/api/static/xxx.jpg` 404 | 用 `resolveStaticUrl()`；`STATIC_ORIGIN` 由 `VITE_STATIC_ORIGIN` 或 `API_BASE_URL` 去 `/api` 得到 |
| 12 | **history 模式刷新 404** | `dist` 部署到 Nginx/静态托管后，直接访问 `/library` 返回 404 | 服务器需 `try_files $uri /index.html`；若无法配置，改用 `createWebHashHistory()`（URL 带 `#`） |
| 13 | **代理与直连混用** | 开了 Vite 代理但仍用绝对 `baseURL`，请求绕过代理 → 误判 CORS 已生效 | 二选一：直连（默认）或 `VITE_API_BASE_URL=/api` + `server.proxy`；不要只改其一 |
| 14 | **HMR 泄漏摄像头** | 修改采集页代码后热更新，旧 `MediaStream` 未 `stop()`，再点开启报 `NotReadableError` | `useCamera` 的 `onBeforeUnmount` + `import.meta.hot.dispose` 双重释放；调试时刷新整页 |
| 15 | **中文 query 双重编码** | `params: { name: encodeURIComponent(name) }` → 后端收到 `%E4%B8%81...` 字面串，删除 0 行 | `params` 传原始姓名，axios 负责编码（`docs/03-04` 坑点 2） |
| 16 | **`.env` 未提交导致队友跑不起来** | 仓库只有 `.env.example`，新克隆环境 `VITE_API_BASE_URL` 为空 → 相对 `/api` 请求打到 5173 | 代码内提供默认值 `http://127.0.0.1:8000/api`，并在 README/本文档写明 `cp .env.example .env.development` |
