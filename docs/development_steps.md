# 人脸识别系统（FaceNet + OpenCV + Web）开发实施总纲

> **仓库**：`face-recognition-facenet-opencv-web`
> **定位**：本文件为全项目开发总纲，串联 5 大阶段、21 个子模块文档，供进度跟踪、里程碑验收与协作分工使用。
> **当前进度**：阶段 1 ~ 3 功能与文档已完成（阶段 2 样本库当前 3/5 人）；阶段 4 未开始
> **文档约定**：每个阶段 / 模块可输出独立文档，统一使用固定字段：**功能背景、开发目标、功能职责、功能逻辑、里程碑计划、验收清单**。

---

## 一、项目概述

构建一套基于 **FaceNet + OpenCV** 的人脸识别系统，支持从底层算法、Web 后端（FastAPI）、Vue 前端到可选 PyQt 桌面 GUI 的完整链路交付。业务上实现：人脸采集入库 → 特征库管理 → 图片识别 → 摄像头实时识别 → 记录删除 的全流程。

## 二、技术架构总览

```text
┌─────────────────────────────────────────────────────────────┐
│  前端展示层                                                  │
│  Vue3 (Vite) Web 界面 / 可选 PyQt 桌面 GUI                   │
└──────────────────────────┬──────────────────────────────────┘
                           │ HTTP JSON（base64 摄像头帧 / 图片）
┌──────────────────────────▼──────────────────────────────────┐
│  后端接口层  FastAPI (api_server.py)                         │
│  Pydantic 数据模型 · CORS · 生命周期管理 · /docs 接口文档      │
└──────────────────────────┬──────────────────────────────────┘
                           │ 函数调用
┌──────────────────────────▼──────────────────────────────────┐
│  核心算法层  backend/                                        │
│  face_detection.py (Haar 检测)                               │
│  face_recognition.py (FaceNet 512维特征 + 余弦相似度)         │
│  db_utils.py (SQLite 特征 Blob 存取)                         │
│  main.py (CLI 业务编排)                                      │
└─────────────────────────────────────────────────────────────┘
```

## 七、风险与注意事项

- **依赖版本**：`opencv-python` 必须锁定 `>=4.8,<4.9`、`numpy` 必须锁定 `>=1.24,<2`。前者避免 CascadeClassifier API 变更报错，后者避免 torch 2.2.2 / opencv 4.8.1 的 NumPy 1.x ABI 冲突（opencv 4.14 又要求 numpy>=2，不可混用）。
- **模型推理**：FaceNet 需支持 CPU/GPU 自动切换；实时识别注意帧率与特征比对耗时平衡。
- **跨域**：前端 dev server 与后端 8000 端口必须配置 CORS，否则浏览器拦截请求。
- **摄像头**：前端需处理 HTTPS/安全上下文下的 MediaDevices 权限限制。
- **分支管理**：PyQt 桌面开发必须隔离在 `pyqt-desktop` 分支，避免污染主流程。
