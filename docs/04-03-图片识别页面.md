## 一、功能背景

图片识别是系统的**核心演示路径**：选一张图 → 后端检测所有人脸 → 逐张与特征库比对 → 前端把「谁、多像、在哪」画回原图。

CLI 版本（`docs/02-02`）在本机做三件事：`detect_faces` → `recognize_face` → `draw_results`（OpenCV 画框写中文）→ `imwrite` 保存。Web 版本必须把这条链路拆成「后端算 → 前端画」：

| 职责 | CLI | Web 后端（`docs/03-03`） | Web 前端（本页） |
|------|-----|--------------------------|------------------|
| 检测 + 比对 | `main.recognize_from_image()` | `POST /api/recognize/image` | 调用接口 |
| 画框 | `main.draw_results()` 写进图片 | 仅 `save_result=true` 时生成 `/static/xxx.jpg` | **默认前端 canvas 叠加绘制** |
| 显示 | `cv2.imshow()` 窗口 | 返回 `result_image_url` | `<img>` + `<canvas>` 绝对定位 |
| 阈值 | `DEFAULT_THRESHOLD = 0.6` 常量 | 表单字段 `threshold`（0.3~0.95） | 滑块实时调参，重新识别生效 |
| 结果文本 | 控制台打印 | `name / similarity / matched / box` | 结果列表 + 图上标签 |

**为什么默认前端画框，而不是只用后端的 `result_image_url`**：

| 方案 | 优点 | 缺点 |
|------|------|------|
| **前端 canvas 叠加（默认）** | 无需落盘、无 `/static` 依赖；框可交互（hover 高亮、点击定位）；识别结果改阈值后无需重新编码图片；实时页可复用 | 需处理坐标缩放与 DPR |
| 后端标注图（`save_result=true`） | 中文渲染由 OpenCV/PIL 负责，效果与 CLI 一致 | 每次识别写一张 jpg，长期运行 `output/results` 膨胀；URL 是 `/static` 需单独拼 origin；框不可交互 |
| 两者并存（默认 canvas + 「下载标注图」勾选） | 兼顾即时反馈与导出 | 多一次可选请求路径，UI 需解释 |

本页采用**第三种但默认不勾选**：主视图永远是 canvas 叠加，`save_result` 作为「导出标注图」开关，勾选后额外展示后端生成的图片链接（可右键另存）。

## 二、开发目标

| 目标 | 说明 |
|------|------|
| 单图识别 | 选择本地图片 → 调用 `/api/recognize/image` → 展示所有人脸的姓名、相似度、坐标 |
| 结果可视化 | canvas 在原图上叠加矩形：命中用绿色，未命中用红色，标签含姓名 + 相似度（4 位小数） |
| 阈值可调 | 0.30~0.95 滑块，默认 0.60；调整后点「重新识别」按新阈值请求（前端不重算相似度） |
| 空库引导 | `library_empty=true` 时展示黄色横幅「特征库为空」+ 「去采集」链接 |
| 无人脸处理 | `1002` 时清空旧框与旧结果，提示换图，不保留上一次的 canvas |
| 导出标注图 | 勾选「保存标注图」→ 后端返回 `result_image_url` → 用 `resolveStaticUrl()` 展示下载链接 |
| 图片前置处理 | 复用 4-2 的 `validateImageFile` / `compressImage`，长边 1600、≤5 MB |
| 性能可见 | 展示后端 `elapsed_ms`、人脸数、命中数、前端耗时 |
| 请求可控 | 识别中禁用按钮；换图/重新识别前 `abort()` 旧请求；取消不提示 |
| 坐标正确 | 原图坐标系 → 显示坐标系等比映射，`devicePixelRatio` 清晰渲染，窗口缩放后重绘 |

## 三、功能职责

| 分类 | 成员 | 职责 |
|------|------|------|
| 页面状态 | `file`、`previewUrl`、`imageSize` | 上传文件、预览地址、原图尺寸 |
| 页面状态 | `threshold`、`saveResult` | 请求参数（滑块 + 开关） |
| 页面状态 | `status`、`errorText`、`notice` | `idle / ready / submitting / done / error` |
| 页面状态 | `result` | `{total_faces, matched_count, elapsed_ms, library_empty, faces[], result_image_url}` |
| 组件方法 | `onFileChange()` / `clearImage()` | 校验、压缩、预览、重置结果 |
| 组件方法 | `recognize()` | 组装参数、`AbortController`、写 `result` / 错误 |
| 组件方法 | `downloadResult()` | 打开或下载后端标注图 |
| 子组件 | `FaceCanvas` | 按容器尺寸缩放绘制框与标签；`hover` 高亮；4-4 复用同一绘制规则（视频覆盖层单独实现） |
| 计算属性 | `matchedFaces` / `hitRate` / `emptyHint` | 列表与摘要渲染 |

**不做的事**：

- 不做前端人脸检测（不引入 face-api.js / MediaPipe，检测口径必须与后端一致）；
- 不做相似度本地重算（阈值改变必须重新请求，否则前端与 CLI/后端结果不一致）；
- 不做多图批量识别（一次一张，避免长任务与进度管理复杂化）；
- 不做结果持久化（`localStorage` 不存人脸数据，刷新即清空）；
- 不做「按姓名过滤」等列表操作（人脸数通常 < 10，直接全展示）。

| 区域 | 数据来源 | 显示规则 |
|------|----------|----------|
| 预览 + canvas | `previewUrl` + `result.faces` | 无结果时只显示原图，不画任何框 |

### 4.2 后端响应到 UI 的字段映射（严格对齐 `docs/03-03`）

```json
{
  "code": 0,
  "message": "识别完成: 2/3 人匹配成功",
  "data": {
    "total_faces": 3,
    "matched_count": 2,
    "elapsed_ms": 318,
    "library_empty": false,
    "faces": [
      { "box": { "x": 412, "y": 180, "w": 210, "h": 210 },
        "name": "张三", "similarity": 0.8731, "matched": true },
      { "box": { "x": 120, "y": 205, "w": 180, "h": 180 },
        "name": null, "similarity": 0.412, "matched": false }
    ],
    "result_image_url": "/static/annotated_20261020_101530_123.jpg"
  }
}
```

| JSON 字段 | 类型 | UI 用途 | 注意 |
|-----------|------|---------|------|
| `total_faces` | int | 摘要「N 张人脸」 | **检测到的人脸数**，不是命中数 |
| `matched_count` | int | 摘要「命中 M」 | 与 `total_faces` 组合算命中率 |
| `elapsed_ms` | int | 摘要耗时 | 仅后端处理时间，不含上传 |
| `library_empty` | bool | 黄色横幅 + 禁用「识别」？ | 不禁止识别，允许用户验证空库行为 |
| `faces[].box` | `{x,y,w,h}` | canvas 画框 | **原图坐标系**，非预览坐标 |
| `faces[].name` | `string \| null` | 标签文本 / 表格姓名 | 未命中为 `null`，显示「未知」 |
| `faces[].similarity` | float | 标签与表格 | 后端已 `round(...,4)`；即使未命中也有值（最高分） |
| `faces[].matched` | bool | 绿/红框、命中与否 | **唯一**判定依据，不要用 `similarity >= threshold` 自行判断 |
| `result_image_url` | `string \| null` | 标注图链接 | 以 `/static` 开头，必须 `resolveStaticUrl()` |

> `matched` 由后端用请求时的 `threshold` 判定。前端若再按当前滑块值重算，会出现「滑块动了一下，框颜色变了但数据没变」的假象——**颜色只跟 `matched` 走**。

### 4.3 选图与识别主流程

```vue
<!-- frontend/src/views/ImageRecognize.vue（核心片段） -->
<script setup>
import { computed, onBeforeUnmount, ref } from 'vue'
import FaceCanvas from '../components/FaceCanvas.vue'
import {
  DEFAULT_THRESHOLD, MAX_UPLOAD_BYTES, THRESHOLD_MAX, THRESHOLD_MIN,
  recognizeByImage,
} from '../api/face'
import { resolveStaticUrl } from '../api/http'
import { compressImage, validateImageFile } from '../utils/image'
import { toUserMessage } from '../utils/errors'

const file = ref(null)
const previewUrl = ref('')
const imageSize = ref({ width: 0, height: 0 })
const threshold = ref(DEFAULT_THRESHOLD)
const saveResult = ref(false)
const appliedThreshold = ref(DEFAULT_THRESHOLD)   // 本次结果实际使用的阈值
const status = ref('idle')                       // idle | ready | submitting | done | error
const errorText = ref('')
const notice = ref('')
const result = ref(null)
const clientMs = ref(0)
let controller = null

const sortedFaces = computed(() => {
  if (!result.value) return []
  return [...result.value.faces].sort((a, b) => (a.box.x - b.box.x) || (a.box.y - b.box.y))
})
const hitRate = computed(() => {
  if (!result.value || !result.value.total_faces) return 0
  return Math.round((result.value.matched_count / result.value.total_faces) * 100)
})
const annotatedUrl = computed(() =>
  result.value && result.value.result_image_url ? resolveStaticUrl(result.value.result_image_url) : '',
)

function resetResult() {
  result.value = null
  errorText.value = ''
  notice.value = ''
  clientMs.value = 0
}

function clearImage() {
  if (controller) { controller.abort(); controller = null }
  if (previewUrl.value) URL.revokeObjectURL(previewUrl.value)
  previewUrl.value = ''
  file.value = null
  imageSize.value = { width: 0, height: 0 }
  status.value = 'idle'
  resetResult()
}

async function onFileChange(event) {
  const picked = event.target.files && event.target.files[0]
  event.target.value = ''
  if (!picked) return
  const invalid = validateImageFile(picked, MAX_UPLOAD_BYTES)
  if (invalid) { errorText.value = invalid; status.value = 'error'; return }
  try {
    const prepared = await compressImage(picked)       // 与 4-2 同一实现（长边 1600 / q0.85）
    file.value = prepared
  } catch (err) {
    errorText.value = err.message || '图片处理失败'
    status.value = 'error'
    return
  }
  if (previewUrl.value) URL.revokeObjectURL(previewUrl.value)
  previewUrl.value = URL.createObjectURL(file.value)
  resetResult()
  status.value = 'ready'
}

async function recognize() {
  if (!file.value) { errorText.value = '请先选择图片'; return }
  if (controller) controller.abort()
  controller = new AbortController()
  status.value = 'submitting'
  errorText.value = ''
  notice.value = ''
  result.value = null
  const startedAt = performance.now()

  try {
    const res = await recognizeByImage(file.value, {
      threshold: Number(threshold.value),
      saveResult: saveResult.value,
      signal: controller.signal,
    })
    result.value = res.data
    appliedThreshold.value = Number(threshold.value)
    clientMs.value = Math.round(performance.now() - startedAt)
    status.value = 'done'
    notice.value = res.data.library_empty
      ? '特征库为空，仅返回人脸位置，未做身份比对'
      : res.message
  } catch (err) {
    if (err.isCanceled) { status.value = file.value ? 'ready' : 'idle'; return }
    errorText.value = toUserMessage(err)
    status.value = 'error'
    result.value = null                              // 1002 等错误必须清空旧框
  } finally {
    controller = null
  }
}

onBeforeUnmount(() => {
  if (controller) controller.abort()
  if (previewUrl.value) URL.revokeObjectURL(previewUrl.value)
})
</script>
```

| 步骤 | 规则 | 说明 |
|------|------|------|
| 选图 | 复用 `validateImageFile` + `compressImage` | 与 4-2 同一套限制，避免「采集能传、识别报 1001」 |
| 预览 | `URL.createObjectURL(file)`，替换前 `revoke` | 压缩后的 Blob 才是实际上传内容，预览与上传一致 |
| 请求参数 | `threshold` 数字、`saveResult` 布尔 → 封装层转字符串 | `save_result` 必须是 `"true"/"false"`，不能是 `undefined`（见 `docs/03-03` 坑点） |
| 重新识别 | 先 `abort()` 旧请求再发新的 | 用户连续点两次只保留最后一次结果 |
| 错误 | 清空 `result` | 否则 `1002` 时旧框仍画在新图上，误导用户 |
| 卸载 | `abort()` + `revokeObjectURL` | 防止离开页面后仍在跑推理 |

> **不要禁用「开始识别」等待库非空**：空库时后端返回 `code=0`、`library_empty=true`、`faces` 带框但 `name=null`。这正是验证检测链路的有效场景，前端只做黄色提示。

### 4.4 覆盖层组件 `FaceCanvas.vue`（4-3 使用；4-4 复用同一绘制规则，不共用组件）

```vue
<!-- frontend/src/components/FaceCanvas.vue -->
<script setup>
import { onBeforeUnmount, onMounted, ref, watch } from 'vue'

const props = defineProps({
  src: { type: String, default: '' },
  faces: { type: Array, default: () => [] },   // [{ box:{x,y,w,h}, name, similarity, matched }]
  showLabels: { type: Boolean, default: true },
  maxHeight: { type: String, default: '60vh' },
})
const emit = defineEmits(['select'])

const wrapRef = ref(null)
const canvasRef = ref(null)
const imgRef = ref(null)
const activeIndex = ref(-1)
let observer = null

function draw() {
  const canvas = canvasRef.value
  const wrap = wrapRef.value
  const img = imgRef.value
  if (!canvas || !wrap || !img || !img.naturalWidth) return
  const rect = wrap.getBoundingClientRect()
  if (!rect.width || !rect.height) return

  const dpr = window.devicePixelRatio || 1
  canvas.width = Math.round(rect.width * dpr)
  canvas.height = Math.round(rect.height * dpr)
  canvas.style.width = `${rect.width}px`
  canvas.style.height = `${rect.height}px`

  const ctx = canvas.getContext('2d')
  ctx.setTransform(dpr, 0, 0, dpr, 0, 0)         // 高清屏 1:1 绘制
  ctx.clearRect(0, 0, rect.width, rect.height)

  const scale = rect.width / img.naturalWidth    // wrap 完全贴合 img，宽高比一致
  props.faces.forEach((face, index) => {
    const { x, y, w, h } = face.box
    const color = face.matched ? '#16a34a' : '#dc2626'
    const left = x * scale
    const top = y * scale
    const width = w * scale
    const height = h * scale
    ctx.lineWidth = activeIndex.value === index ? 4 : 2
    ctx.strokeStyle = color
    ctx.strokeRect(left, top, width, height)

    if (!props.showLabels) return
    const label = face.matched
      ? `${face.name} ${(face.similarity * 100).toFixed(1)}%`
      : `未知 ${(face.similarity * 100).toFixed(1)}%`
    ctx.font = '13px system-ui, -apple-system, "Segoe UI", sans-serif'
    const tagW = ctx.measureText(label).width + 8
    const tagH = 20
    const tagTop = top - tagH >= 0 ? top - tagH : top
    ctx.fillStyle = color
    ctx.fillRect(left, tagTop, tagW, tagH)
    ctx.fillStyle = '#fff'
    ctx.textBaseline = 'middle'
    ctx.fillText(label, left + 4, tagTop + tagH / 2)
  })
}

function setActive(index) {
  if (index === activeIndex.value) return
  activeIndex.value = index
  emit('select', index >= 0 ? props.faces[index] : null) // 移出时发 null，便于页面取消高亮
  draw()
}

function onMove(event) {
  const img = imgRef.value
  if (!img || !img.naturalWidth) return
  const rect = img.getBoundingClientRect()
  const scale = rect.width / img.naturalWidth
  const px = (event.clientX - rect.left) / scale
  const py = (event.clientY - rect.top) / scale
  const index = props.faces.findIndex(({ box }) =>
    px >= box.x && px <= box.x + box.w && py >= box.y && py <= box.y + box.h)
  setActive(index)
}

function onLeave() {
  setActive(-1)
}

watch(() => [props.faces, props.src], draw, { deep: true })
onMounted(() => {
  if (typeof ResizeObserver !== 'undefined') {
    observer = new ResizeObserver(() => draw())
    if (wrapRef.value) observer.observe(wrapRef.value)
  }
  window.addEventListener('resize', draw)
})
onBeforeUnmount(() => {
  observer && observer.disconnect()
  window.removeEventListener('resize', draw)
})

defineExpose({ redraw: draw })
</script>

<template>
  <div ref="wrapRef" class="face-canvas" @mousemove="onMove" @mouseleave="onLeave">
    <img ref="imgRef" :src="src" :style="{ maxHeight }" alt="待识别图片" @load="draw">
    <canvas ref="canvasRef" class="face-canvas__layer" />
  </div>
</template>

<style scoped>
.face-canvas { position: relative; display: inline-block; line-height: 0; max-width: 100%; }
.face-canvas img { display: block; max-width: 100%; height: auto; border-radius: 6px; }
.face-canvas__layer { position: absolute; inset: 0; pointer-events: none; }
</style>
```

| 设计点 | 处理 | 理由 |
|--------|------|------|
| 容器尺寸 | `display:inline-block` 包裹 `<img>`，由图片撑开 | 排除 `object-fit: contain` 留白，坐标换算只需一个 `scale` |
| 坐标换算 | `scale = rect.width / naturalWidth`，框 = `x*scale, y*scale...` | `box` 是**原图**坐标，不是预览坐标 |
| 高清屏 | `canvas.width = cssWidth * dpr` + `setTransform(dpr,...)` | 否则 2x 屏上线宽 2px 变 1px、文字发虚 |
| 重绘时机 | `img @load`、`faces/src` 变化、`ResizeObserver`、`window resize` | 图片加载完成前 `naturalWidth=0`，画了也是空 |
| 交互 | `mousemove` 命中测试 → 高亮 + `select` 事件 | 4-3 点击可滚动到表格行；4-4 显示当前跟踪目标 |
| 层叠 | canvas `pointer-events: none`，事件挂在容器 | 避免 canvas 抢占 `img` 的拖拽/右键另存 |
| 未命中样式 | 红色框 + `未知 xx.x%` | 与 CLI `draw_results` 的「Unknown」语义一致 |

> 标签里的百分比是 `similarity`（最高余弦相似度），**不是**阈值；是否命中只看 `matched`。`docs/03-03` 已把 `similarity` 保留 4 位小数，这里乘 100 取 1 位显示，避免「0.8731」在图上过长。

### 4.5 结果表格与空库提示

```vue
<template>
  <section v-if="result" class="card">
    <div class="summary">
      <span>{{ result.total_faces }} 张人脸</span>
      <span>命中 {{ result.matched_count }}（{{ hitRate }}%）</span>
      <span>后端 {{ result.elapsed_ms }} ms · 前端往返 {{ clientMs }} ms</span>
```

| 显示项 | 规则 | 备注 |
|--------|------|------|
| 姓名 | `face.name || '未知'` | 空库时全为「未知」，属预期 |
| 相似度 | `toFixed(4)` | 与后端 `round(...,4)` 一致，不四舍五入两次 |
| 状态 | `matched ? '命中' : '未命中'` | 以布尔为准 |
| 排序 | `box.x` 升序，同列再按 `box.y`，仍相同则保持后端顺序（`index` 兜底） | 与「从左到右、从上到下」的阅读习惯一致，排序稳定 |
| 行同步 | `FaceCanvas` 悬停时 `emit('select', face)`，移出/空白处 `emit(null)` | 页面用 `activeFace` 高亮对应行，避免悬停残留 |
| 空结果 | 只在 `code=0 且 faces=[]` 时出现 | `1002` 走错误分支，`result=null`，整块不渲染 |
| 标注图 | `<a target="_blank" rel="noopener">` | `noopener` 防止新窗口拿到 `window.opener` |
| 标注图地址 | `resolveStaticUrl(result_image_url)` 拼 `VITE_STATIC_ORIGIN`；`http(s)://` 原样返回 | `/static` 不在 `/api` 下，不能拼 `API_BASE_URL`（04-01 坑点） |
| 未返回地址 | 本次勾选了保存但 `result_image_url` 为空 → 提示可能未配置 `RESULT_DIR`；未勾选则不提示 | 区分「没勾选」与「勾了但生成失败」，避免误报 |

> 实际实现把空库提示合并进 `#recognize-notice`（`alert--warning` + `role="status"`），并内嵌 `<RouterLink id="library-empty-link" to="/collect">去采集人脸</RouterLink>`：一次播报完成「原因 + 下一步」，也避免两个 `role="status"` 同时抢读屏。

### 4.6 阈值滑块与「保存标注图」开关

```vue
<div class="control">
  <label for="threshold">
    相似度阈值 <strong>{{ Number(threshold).toFixed(2) }}</strong>
  </label>
  <input
    id="threshold" v-model.number="threshold" type="range"
    :min="THRESHOLD_MIN" :max="THRESHOLD_MAX" step="0.01"
    :disabled="status === 'submitting'"
  >
  <p class="hint">
    范围 {{ THRESHOLD_MIN.toFixed(2) }} ~ {{ THRESHOLD_MAX.toFixed(2) }}，步长 0.01；默认 {{ DEFAULT_THRESHOLD }}。
    越高越严格（误认少、漏认多），越低越宽松。
    调整后需重新识别，颜色不会随滑块即时改变。
  </p>

  <label class="checkbox">
    <input v-model="saveResult" type="checkbox" :disabled="status === 'submitting'">
    保存标注图（后端生成 /static/*.jpg，便于下载留档）
  </label>

  <button class="btn btn--primary" :disabled="!file || status === 'submitting'" @click="recognize">
    {{ status === 'submitting' ? '识别中…' : '开始识别' }}
  </button>
</div>
```

| 参数 | 范围 | 默认 | 校验位置 | 越界后果 |
|------|------|------|----------|----------|
| `threshold` | 0.30 ~ 0.95（`step 0.01`） | 0.60（`DEFAULT_THRESHOLD`） | 滑块 `min/max` + 后端路由校验 | 后端返回 `1001`「阈值必须在 0.3~0.95 之间」 |
| `save_result` | `true / false` | `false` | 封装层转 `'true'/'false'` | 传空串或 `undefined` → `422` |

> **滑块不触发自动重识别**：每次识别都是一次同步推理（`_infer_lock`），拖动滑块连发 10 个请求会排队并把后端的忙标记打满（`1008`）。只在点击「开始识别」时读取当前值，并在结果区标注 `appliedThreshold`，让用户明确「这个结果是用哪个阈值算的」。

### 4.7 错误处理与状态重置

| `code` | 触发场景 | 页面处理 | 必须重置的 UI |
|--------|----------|----------|----------------|
| `0` | 正常 | 渲染 canvas + 表格 | — |
| `1001` | 文件损坏 / 阈值越界 / 名称超长 | 红字 `message` | `result = null` |
| `1002` | 图中无人脸 | 红字「未检测到人脸…」 | `result = null`（**清空旧框**） |
| `1003` | 特征提取失败（极少数坏图） | 红字，建议换图 | `result = null` |
| `1007` | 服务内部错误 | 红字 + 提示查看后端日志 | `result = null` |
| `1008` | 推理忙（并发占锁） | 红字「繁忙，请稍后重试」 | 保留上一次结果？**否**，本次无结果 |
| `422` | 缺 `file` / `threshold` 非法字符串 | 红字 `message` | `result = null` |
| `-1` | 后端未启动 / CORS 失败 | 红字 + 重试提示 | `result = null` |
| `-2` | 超时（60 s） | 红字「推理超时」，建议缩小图片 | `result = null` |
| `-3` | 主动取消（换图 / 重识别） | **静默**，不写提示 | 由新请求接管 |

```js
// 统一错误分支（页面只写这一处 catch）
} catch (err) {
  if (err.isCanceled) { status.value = file.value ? 'ready' : 'idle'; return }
  errorText.value = toUserMessage(err)
  status.value = 'error'
  result.value = null
  appliedThreshold.value = Number(threshold.value)
}
```

| 重置动作 | 触发点 | 目的 |
|----------|--------|------|
| `result = null` | 换图 / 识别失败 / 清空 | 防止「新图上画着旧框」 |
| `appliedThreshold` 更新 | 识别成功 / 失败 | 结果区显示的阈值始终是本次请求值 |
| `status = 'ready'` | 取消 | 允许再次点击，不闪错误 |
| `revokeObjectURL` | 换图 / 卸载 | 释放 Blob |

### 4.8 性能与坐标精度

| 指标 | 目标 | 说明 |
|------|------|------|
| 选图到可点「识别」 | < 800 ms（4 MB 图） | 压缩是主要耗时，复用 4-2 实现 |
| 请求往返（含上传，局域网） | < 1.5 s（CPU，单脸） | 后端 `elapsed_ms` 通常 150~600 ms |
| canvas 重绘 | < 16 ms | 人脸数 < 20 时无压力；`ResizeObserver` 已做去抖（浏览器帧内合并） |
| 首屏 chunk | < 60 KB | 路由懒加载 + 组件按需 |

坐标精度相关：

- `box` 为整数像素、原图坐标系；`scale` 用浮点计算，绘制时不再取整，避免累积偏移；
- `canvas` 尺寸按 `dpr` 放大，`setTransform` 统一缩放，**不要**在绘制坐标上再乘 `dpr`；
- 图片被 CSS `max-width` 缩放后，`naturalWidth` 仍是原图宽度，是唯一可靠的换算基准；
- 若后端对长边 > 1280 的图先缩小检测再还原坐标（`docs/03-05` 坑点 11），前端拿到的 `box` 已经是原图坐标，**不要**再乘任何检测缩放比。

### 4.9 可访问性与交互细节

- 结果表用语义化 `<table>` + `<th>`，屏幕阅读器可读出列名；
- 「开始识别」按钮在 `status === 'submitting'` 时 `disabled` 且文案变为「识别中…」，不只靠颜色区分；
- 空库横幅使用 `role="status"`，错误使用 `role="alert"`；
- 图片 `alt` 为「待识别图片」，避免读屏器朗读 base64；
- 阈值滑块有可见数值与说明，键盘左右键可调（原生 `range`）；
- 支持把图片直接拖入页面（可选增强：`dragover` 阻止默认 + `drop` 取 `dataTransfer.files[0]` 复用 `onFileChange` 逻辑）。

## 七、异常点与坑点

| # | 问题 | 现象 | 定位与处置 |
|---|------|------|------------|
| 1 | **误用预览坐标** | 框整体偏小、集中在左上角 | `box` 是原图坐标，必须乘 `rect.width / naturalWidth`；不要用预览的 `clientWidth / 预览宽` |
| 2 | **`naturalWidth=0` 时绘制** | 首次识别后无任何框，缩放窗口才出现 | 绘制在 `img @load` 与 `faces` 变化后都执行；`faces` 到达时图片可能尚未 onload |
| 3 | **忘记乘 DPR** | 2x 屏上框线只有 1 物理像素、文字模糊 | `canvas.width = cssW * dpr` + `ctx.setTransform(dpr,0,0,dpr,0,0)` |
| 4 | **canvas 尺寸与 img 不一致** | 框向右下偏移，右下角框被裁掉 | 用 `display:inline-block` 包裹让容器贴合图片，或按 `object-fit` 计算留白；本页选前者 |
| 5 | **按相似度重算 matched** | 拖动滑块后颜色变了但数据没变 | 颜色与状态只读 `face.matched`；阈值改变必须重新请求 |
| 6 | **阈值改后不重新识别** | 用户以为结果已按新阈值更新 | 结果区展示 `appliedThreshold`，并在滑块旁写「调整后需重新识别」 |
| 7 | **`save_result` 布尔序列化** | 传 `false` 变成 `"false"` 正常，传 `undefined` 变空串 → 422 | 封装层强制 `saveResult ? 'true' : 'false'` |
| 8 | **`result_image_url` 拼到 `/api` 下** | 图片 404，Network 显示 `/api/static/...` | 用 `resolveStaticUrl()`；`/static` 挂在根路径 |
| 9 | **后端写盘失败** | 勾选了保存但 `result_image_url=null`，无任何提示 | 后端吞掉异常只写日志；前端在勾选时说明「保存失败不影响识别结果」，`null` 时隐藏该行 |
| 10 | **`1002` 不清旧状态** | 换风景图识别后，旧人脸的框还在 | `catch` 里 `result = null`；同时清空 `notice` |
| 11 | **`1008` 误当严重错误** | 连续点识别时弹「系统错误」 | 文案改为「推理服务繁忙，请等待上一次完成」，并禁用按钮 |
| 12 | **取消被当成失败** | 换图时闪一下红色「请求已取消」 | `err.isCanceled` 直接 `return`，状态回 `ready` |
| 13 | **大图慢/超时** | 4 MB 原图上传 + CPU 推理 > 30 s | 复用压缩（长边 1600）；超时 60 s；提示「请缩小图片」 |
| 14 | **EXIF 旋转** | 预览是正的，后端检测不到人脸 | 压缩阶段用 `createImageBitmap` 按 EXIF 解码后重编码，保证上传字节与预览一致 |
| 15 | **中文标签乱码** | canvas 上文字显示为方块 | 用系统字体栈（`system-ui`）而非 OpenCV；若字体缺失，中文仍可显示，不像 `cv2.putText` 只能英文 |
| 16 | **`box` 越界** | 框超出图片边界（检测框贴边） | canvas 会自然裁剪，无需 clamp；表格仍显示原始坐标 |
| 17 | **`faces` 为空但 `code=0`** | 表格区空白，用户以为坏了 | 显示「未检测到人脸」空态行；同时 `total_faces=0` 摘要可读 |
| 18 | **`<a>` 打开静态图被拦** | 部分浏览器 `target=_blank` 被弹窗拦截 | 用普通链接（用户点击，不属脚本弹窗）；提供「复制链接」按钮兜底 |
